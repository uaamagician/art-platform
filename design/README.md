# 設計稿（草稿）

這些只是讓大家看看 App 大概長怎樣的參考圖，不是定案。美術、介面組可以照自己的想法整個重做。

- `png/existing/`　目前 App 的畫面（含彈窗、空狀態）
- `png/planned/`　還沒做的功能的想法，右邊有簡單說明
- `svg/`　同樣的圖，拖進 Figma 後文字跟顏色可以改，按鈕、標籤這些也有分組命名
- `gallery.html`　用瀏覽器打開，一頁看完

## 怎麼看

直接看 `png` 就好。想拿來改的話可以把 `svg` 拖進 Figma（字型用 Noto Sans TC 比較不會跑位）。
